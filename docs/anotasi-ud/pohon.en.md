# Dependency Trees

Each arc links a head word to its dependent, with the UD relation name above the arc. The row below each word shows its part of speech (UPOS). The `root` arc marks the predicator as the root of the sentence.

The examples below come directly from Section 8 of the latest [annotation guideline](pedoman.md). Once double annotation and adjudication are complete, the 250 pilot sentences will be shown on this page.
